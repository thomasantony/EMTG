The Testatron regression tests reference two launch vehicle library files that
are not committed directly to this folder:

  NLSII_April2017.emtg_launchvehicleopt
  NLSII_August2018.emtg_launchvehicleopt

These can be obtained by running the setup script from the testatron directory:

  python get_data_files.py    (cross-platform)
  bash get_data_files.sh      (Linux / macOS)

The script copies the publicly distributable NLS-II launch vehicle data file
that is included with the EMTG tutorial:

  docs/0_Users/tutorial/Tutorial_EMTG_Files/Config_Files/hardware_models/
      LaunchVehicles_PubliclyDistributable_NLSII.emtg_launchvehicleopt

That file contains polynomial performance models for:
  Atlas_V_401, Atlas_V_411, Atlas_V_421, Atlas_V_431,
  Atlas_V_501, Atlas_V_511, Atlas_V_521, Atlas_V_531,
  Atlas_V_541, Atlas_V_551, Atlas_V_541_Star48BV, Atlas_V_551_Star48BV,
  Delta_IV_Heavy,
  Falcon_9_FT_(RTLS), Falcon_9_FT_(ASDS),
  Falcon_Heavy_(RecoveryAug2018), Falcon_Heavy_(ExpendableAug2018),
  Antares_232,
  Fixed_Initial_Mass, Depart_With_Spacecraft_Thrusters

This covers all launch vehicle keys used by the Testatron test suite.

----

Background: the original NLS-II files (from the NASA Launch Services Program
contract) are not publicly releasable. The tutorial file above is a publicly
distributable subset derived from the same data source and was released
alongside the EMTG open-source distribution.

File format reference (space-delimited):
  name  ModelType  DLA_lower(deg)  DLA_upper(deg)  C3_lower  C3_upper  coeff[0]  coeff[1]  ...

ModelType 0: standard polynomial, ith coefficient = ith power of C3 (km^2/s^2),
             performance output in kg.
