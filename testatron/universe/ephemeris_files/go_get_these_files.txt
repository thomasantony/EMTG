The easiest way to get all required ephemeris files is to run the setup
script from the testatron/ directory:

  python get_data_files.py    (cross-platform)
  bash get_data_files.sh      (Linux / macOS)

The script downloads all of the files listed below automatically.

-------------------------------------------------------------------------------
Required SPICE kernels (all from https://naif.jpl.nasa.gov)
-------------------------------------------------------------------------------

Leap seconds kernel:
  naif0012.tls
  https://naif.jpl.nasa.gov/pub/naif/generic_kernels/lsk/naif0012.tls

Planetary constants kernel:
  pck00010.tpc
  https://naif.jpl.nasa.gov/pub/naif/generic_kernels/pck/pck00010.tpc

Planetary ephemeris:
  de430.bsp  (~114 MB)
  https://naif.jpl.nasa.gov/pub/naif/generic_kernels/spk/planets/de430.bsp

Mars satellite kernel (required by Mars-related tests):
  mar099.bsp
  https://naif.jpl.nasa.gov/pub/naif/generic_kernels/spk/satellites/mar099.bsp

Jupiter satellite kernel (required by Jupiter-related tests):
  jup365.bsp
  https://naif.jpl.nasa.gov/pub/naif/generic_kernels/spk/satellites/jup365.bsp

300-asteroid SPK (required by Earth_to_SmallBody_SAM* tests):
  codes_300ast_20100725.bsp  (~59 MB)
  https://naif.jpl.nasa.gov/pub/naif/generic_kernels/spk/asteroids/codes_300ast_20100725.bsp

  Contains ephemeris for 300 numbered asteroids including body 2000336
  (asteroid 336 Lacadiera), which is used as the small-body target in
  the SAM regression tests (SmallBody.emtg_universe / Sun_SmallBodyOrbiter).
